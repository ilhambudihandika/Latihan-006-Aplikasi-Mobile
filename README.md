# Aplikasi Profil

Project Flutter untuk tugas mata kuliah Aplikasi Mobile. Aplikasi ini menampilkan halaman profil sederhana menggunakan Flutter.

## Fitur
- Foto profil mahasiswa
- Nama mahasiswa
- Jurusan mahasiswa
- Tampilan profil dengan background abu-abu
- Widget profil yang dipisah menjadi beberapa bagian

## Struktur Widget
- `MyApp`
- `ProfilePage`
- `ProfileAvatar`
- `ProfileInfo`

## Perkembangan
Hari pertama mengembangkan halaman profil dengan memisahkan bagian foto dan informasi mahasiswa ke dalam widget tersendiri agar kode lebih rapi dan mudah dikelola.
