# Aplikasi Profil

Project Flutter untuk tugas mata kuliah Aplikasi Mobile. Aplikasi ini menampilkan halaman profil mahasiswa menggunakan Flutter.

## Fitur
- Foto profil mahasiswa
- Nama dan jurusan mahasiswa
- Statistik Projects
- Statistik Followers
- Statistik Following
- Tampilan kartu informasi mahasiswa

## Struktur Widget
- `MyApp`
- `ProfilePage`
- `ProfileAvatar`
- `ProfileInfo`
- `ProfileStats`
- `StatItem`

## Perkembangan
Pada hari kedua, merapikan kode dengan memisahkan bagian statistik menjadi widget ProfileStats dan StatItem. Tampilan profil juga diperbarui agar informasi mahasiswa terlihat lebih rapi.
