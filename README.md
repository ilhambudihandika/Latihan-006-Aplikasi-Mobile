
# Aplikasi Profil

Project Flutter untuk tugas aplikasi mobile. Aplikasi ini menampilkan profil mahasiswa dengan nama, jurusan, email, dan tombol edit profil.

## Fitur
- Profil mahasiswa
- Nama dan jurusan
- Email mahasiswa
- Tombol Edit Profil

## Perkembangan
Hari kedua menambahkan informasi email pada halaman profil.
