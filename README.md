
# Aplikasi Profil

Project Flutter untuk tugas aplikasi mobile. Aplikasi ini menampilkan profil mahasiswa, mulai dari nama, jurusan, sampai tombol edit profil.

## Fitur
- Profil mahasiswa
- Nama dan jurusan
- Tombol Edit Profil

## Perkembangan
Hari pertama membuat tampilan profil sederhana menggunakan Flutter.
