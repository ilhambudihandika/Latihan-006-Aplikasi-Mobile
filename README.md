# Aplikasi Profil

Project Flutter untuk tugas mata kuliah Aplikasi Mobile. Aplikasi ini menampilkan halaman profil sederhana menggunakan Flutter.

## Fitur
- Foto profil
- Nama mahasiswa
- Jurusan mahasiswa

## Perkembangan
Hari pertama membuat kerangka awal halaman profil menggunakan Scaffold, AppBar, CircleAvatar, dan Text.
