# Aplikasi Profil

Project Flutter untuk tugas mata kuliah Aplikasi Mobile. Aplikasi ini menampilkan halaman profil mahasiswa menggunakan Flutter.

## Fitur
- Foto profil mahasiswa
- Nama dan jurusan mahasiswa
- Statistik Projects
- Statistik Followers
- Statistik Following

## Struktur Widget
- `MyApp`
- `ProfilePage`
- `ProfileAvatar`
- `ProfileInfo`
- `ProfileStats`

## Perkembangan
Pada hari kedua, menambahkan bagian statistik profil yang menampilkan jumlah Projects, Followers, dan Following menggunakan Row dan Column.
