# Aplikasi Profil

Project Flutter untuk tugas mata kuliah Aplikasi Mobile. Aplikasi ini menampilkan halaman profil mahasiswa menggunakan Flutter.

## Fitur
- Foto profil mahasiswa
- Nama dan jurusan mahasiswa
- Statistik Projects, Followers, dan Following
- Daftar pengalaman mahasiswa
- Ikon pada setiap daftar pengalaman
- Tampilan kartu dengan bayangan
- Pengaturan jarak dan padding antar-komponen

## Struktur Widget
- `MyApp`
- `ProfilePage`
- `ProfileAvatar`
- `ProfileInfo`
- `ProfileStats`
- `StatItem`
- `ExperienceCard`

## Perkembangan
Pada hari keempat, merapikan tampilan halaman profil dengan menyesuaikan padding dan jarak antar-komponen. Pengaturan ini dilakukan agar setiap bagian terlihat lebih rapi dan nyaman dilihat.
